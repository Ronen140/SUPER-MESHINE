## Folders

- **Meeting Notes/** — features, code, bugfixes, architecture sessions
- **Architecture Decisions/** — ADRs (Architecture Decision Records), one per decision
- **Domain Knowledge/** — ERP / accounting / inventory / MRP / FDA reference material
- **Discovery/** — customer interview notes, vertical research, competitor analysis

## Conventions

- Filenames: `lowercase-hyphenated.md`, no date in name.
- New session entries appended at the **bottom** of `## Session Log`.
- Status tags on every session heading: `[active]`, `[blocked]`, `[done]`, `[abandoned]`.
- Wikilinks for cross-references: `[[topic-name]]`.
